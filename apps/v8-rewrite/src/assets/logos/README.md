# Organisation logos

Official logo files for the "experience from" row on the front page. One file per organisation,
SVG preferred (PNG works), named by the slug of the name in `team.experienceFrom`:

    maluuba  microsoft  university-of-waterloo  y-combinator  mila  vector-institute

A name with no file here is shown as a text tag instead. Use only files the organisation publishes
for this purpose, unaltered, and check each one's brand guidelines before launch.

## What is here

- `mila.svg`: Mila (Quebec AI Institute), from https://mila.quebec/sites/default/themes/mila_v1/logo.svg
  (downloaded 2026-10-13 with Ankit's OK), recoloured from its purple to ink. Original in `originals/mila.svg`.
- `maluuba.png`, `microsoft.png`, `university-of-waterloo.png`, `y-combinator.png`, `vector-institute.png`:
  monochrome ink on a transparent background, made from the files in `originals/` (Ankit, 2026-10-13).
- `university-of-toronto.png`, `amii.png`: monochrome ink on a transparent background, made from the
  files Ankit supplied on 2026-10-18 (in `originals/`).
- `ycombinator.png`: a copy of `y-combinator.png` so the rewrite's "YCombinator" spelling finds it.
- `originals/`: the files exactly as supplied, kept for later use. Not bundled into the site.
- `originals/mila-university-NOT-mila-quebec.png` is the logo of Mila University, a different
  organisation from Mila, the Quebec AI Institute named in the content doc. It is not used.
- The Microsoft original came with a stock-site watermark and a baked checkerboard; both are removed
  in the monochrome version. Replace it with a file from Microsoft's own brand page before launch.

## Investors (`investors/`)

- `fidelity.png`, `touring-capital.png`, `m13.png`, `inovia-capital.png`: the investor logos for the
  "support of our investors" section, named by the slug of each name in `backers.investors`. Made
  from the files Ankit supplied (2026-10-14, in `investors/originals/`): white background removed,
  recoloured to the same monochrome ink as the logos above, lighter tones kept as lighter greys.
